# Contributing

Thanks for improving the AI Coding Workflow Starter Pack.

## Good contributions

- clearer templates
- real project examples
- better verification checklists
- safer AI-agent boundaries
- corrections for tool behavior that changed

## Keep it practical

Avoid vague rules like:

```text
Write clean, scalable, robust code.
```

Prefer concrete rules like:

```text
Run `npm run typecheck`, `npm run lint`, and `npm run build` before reporting success.
```

## No secrets

Do not commit API keys, tokens, webhook URLs, private customer data, or real `.env` files.

## Style

- Use Markdown.
- Keep examples copyable.
- Mark placeholders clearly.
- Prefer short checklists over theory dumps.
