# AGENTS.md - Content site example

## Project purpose

This is a content/SEO website. The main goals are helpful articles, internal links, clean metadata, and fast pages.

## Stack

- Static or hybrid site framework
- Markdown/MDX content
- Image assets in `public/` or `assets/`
- Deployed on Vercel/Netlify/static hosting

## Commands

```bash
npm install
npm run lint
npm run build
```

## Content rules

- Keep titles clear and search-intent aligned.
- Do not invent facts, tool behavior, or pricing.
- Add internal links where useful.
- Keep examples practical and copyable.
- Check image alt text and metadata.

## Safety rules

- Do not publish without approval.
- Do not commit private strategy notes or client information.
- Do not use copyrighted images without permission.
